# 苹果 Liquid Glass B+C 动效展示型设计

- 日期：2026-11-28
- 基线：v3.0.0-test9（versionCode 143）
- 目标交付：v3.0.0-test10（versionCode 144）
- 状态：用户已确认 B+C 路线，批准执行测试版
- 范围：液态玻璃材质、动效优先级、信息层级、关键流程连续性与性能安全

## 1. 用户意图

用户认为 test9 已经具备基础苹果动效，但希望进一步“真正苹果化”，并在评审后明确选择：

- B：Liquid Glass 展示型——材质、折射、色散和通透层级是第一视觉语言。
- C：动效优先型——按压、预测返回、共享元素、弹簧回弹、拖拽和状态切换要有清晰手感。
- 同时保留 A 路线的克制信息设计，避免效果堆砌成主题皮肤。

目标不是“动画越多越好”，而是：**关键材质拉满，关键动作连续，次要信息安静，真机稳定不降级。**

## 3. 第一性原理

1. **因果**：每个动画必须由点击、拖拽、返回或数据状态变化触发。
2. **连续**：同一照片、按钮、卡片在状态之间保持身份和空间连续。
3. **克制**：同一时刻只有一个主动画层级；背景、次要卡片和无限循环保持安静。
4. **可逆**：手势取消、返回、失败、弹窗关闭都能回到稳定状态。
5. **真实**：模拟器只验证功能与方向，不把模拟器帧率冒充真机性能。

## 4. 设计目标

- 主页、选择器、原图查看器、设置、修复页、弹窗和 Sheet 形成统一的 Liquid Glass 语言。
- Thin / Regular / Thick 不只是透明度差异，而是 blur、refraction、highlight、dimming 的整体层级。
- 所有关键可点元素有即时按压、松开回弹、取消回稳和语义反馈。
- 照片从网格到查看器、页面返回、Sheet 拖拽、网格转换状态都有空间或时间连续。
- Loading / Empty / Error / Success 不硬切，不滞后，不出现假空态。
- 减少动效下移除位移、形变、无限循环和闪白，保留状态与触觉。
- 真机稳定性、数据安全、转换/MediaStore/删除语义零变化。

## 5. 材质设计

### 5.1 Thin

用于顶部导航、Chip、图标按钮、查看器顶栏等需要保持清晰的层。

- 较低白膜透明度，保留背景内容。
- 边缘高光更细，折射幅度收敛。
- 禁止 Backdrop/AGSL 路径，避免小节点 RenderThread 风险。
- 按压只允许轻微 scale 与触点高光，不新增渲染层。

### 5.2 Regular

用于内容卡、设置分组、相册行、常规面板。

- 平衡通透与可读性。
- 深色主题使用暗烟玻璃，浅色主题使用冷白玻璃。
- 选中态通过 tint、边缘和轻微形变表达，不依赖重阴影。

### 5.3 Thick

用于底部 Dock、全屏 Sheet、高文本密度弹窗、原图查看器底栏。

- 提高不透明度和压暗，保证文字与主操作清晰。
- 边缘折射更深，顶部偏青蓝、底部偏玫橙的色散只在活跃/按压时增强。
- 允许更强的镜面高光，但禁止持续彩虹辉光。
- Backdrop 仅用于短边 ≥96dp 的节点；其余回退 Haze 或稳定玻璃膜。

### 5.4 背景联动

- 主页和查看器使用当前首选照片的低成本缩略图作为氛围采样源。
- 页面可见背景不改变，照片不上传、不落盘、不增加新的权限。
- 平滑渐变上保留极淡采样纹理，确保折射可读。
- 兼容模式关闭实时折射，只保留材质膜、状态色和按压反馈。

## 6. 信息设计

- 主页使用克制 Large Title；滚动后收成紧凑标题。
- 设置子页使用紧凑标题和分组列表，减少卡片套卡片。
- 已选数量、进度、文件名使用等宽数字；颜色只表达语义。
- 列表/网格使用分段控件；开关、Chip、按钮统一字重、触控尺寸和选中态。
- 空态/错误态统一为一个图标、一个结论、一句解释、至多一个主动作。
- 页面边距、内部间距、圆角、图标尺寸继续遵循现有 12dp 网格与连续曲率规范。

## 7. 动效合同

### 7.1 按压

- 按下立即响应，scale 目标 0.96–0.98f，使用 Snappy 弹簧。
- 触点高光跟随手指，松开回弹；减少动效直接 snap。
- Haze 只增强 refraction/lighting，膨胀仍由 graphicsLayer 承担，避免双重缩放。
- 确认、完成、失败触觉同帧且只触发一次。

### 7.2 导航

- 普通子页：轻微 scale + fade，保持来源页稳定。
- 设置层级：横向共享轴过渡，不引入新 Navigation 框架。
- 预测返回：跟手进度、取消回弹、提交续接；忙碌修复页消费返回。
- 退场中的 Viewer/Sheet 不再吞第二次返回。

### 7.3 照片英雄转场

- 网格缩略图到全屏查看器使用同一个 SharedContentState。
- 图片 bounds 使用 Gentle 弹簧；顶栏、底栏和背景分层进入。
- 查看器支持双指缩放、双击放大、左右翻页；返回先复位缩放再关闭。
- 中途关闭可打断；减少动效直接切换，不做尺寸动画。

### 7.4 Sheet

- 相册面板支持拖拽关闭、速度阈值和回弹吸附。
- 遮罩淡入、面板弹簧上滑；退场更快。
- 当前相册有选中态、封面、名称、张数和勾选标记。
- 拖拽或返回关闭后立即停止触摸和动画。

### 7.5 网格转换

- 待转换 → 转换中：状态文字即时更新，暗幕和单转圈进入。
- 转换中：每张卡片最多一个无限 spinner；进度条只在 Dock 出现一次。
- 完成：低透明度闪白 + 徽标弹入 + CONFIRM 触觉。
- 失败/丢位置：徽标、语义色、短抖动和拒绝触觉。
- 批量并发时降低非关键动画，不让每张卡片同时抢镜。

### 7.6 状态编排

- StateCrossfade 统一 fade 与 SizeTransform；减少动效 snap。
- GlassLoadingSkeleton 每个可见容器只有一个 shimmer 相位。
- 滚动或不可见时停止 shimmer 与缩略图 pulse。
- 错误态保留重试；成功态不弹无意义 Toast。

## 8. 性能预算

- 小尺寸节点不新增 Backdrop/AGSL/RenderEffect。
- Backdrop 最小短边 96dp，Thin 永不进入 Backdrop。
- 每个可见容器最多一个无限动画；离屏、滚动、减少动效时停止。
- Haze/Backdrop 成本继续受标准/流畅档和滚动暂停控制。
- 关键路径记录帧时间与 PSS；模拟器数据只作基线，真机数据才作最终结论。
- 若真实设备出现原生崩溃或持续 jank，优先降级到兼容玻璃膜，不强行保留效果。

## 9. 可访问性

- 所有可点元素 ≥48dp，语义包含 role、selected、toggle、progress 与 content description。
- 骨架屏使用 Indeterminate progress，不误报 0%。
- 深色、浅色、2× 字号、减少动效、兼容模式全部进入矩阵。
- 触觉不替代视觉状态；颜色不替代文字和图标。
- 动画可取消、可打断，不阻塞关键操作。

## 10. 验证计划

- JVM：MotionTokens、玻璃层级、Backdrop guard、控件语义、状态切换、返回优先级、忙碌修复保护。
- Compose UI：按压/释放/取消、共享元素打开/关闭、Sheet 拖拽、网格状态、减少动效。
- 截图矩阵：浅/深、标准/流畅、2× 字号、减少动效、兼容模式、照片氛围。
- host GPU 模拟器：主页、Picker→Viewer→返回、AlbumSheet、设置、修复页、网格转换。
- 记录 `dumpsys gfxinfo` 与 `meminfo`，不宣称真机性能。
- 全量测试、lint、R8、v3 签名 Release、CI、附件哈希/证书/revision 核验。
- 真机视觉、GPU 兼容性和性能仍需用户安装后确认；正式 3.0 不在本版自动发布。

## 11. 非目标

- 不改转换管线、MediaStore、删除/恢复、分享导入和数据格式。
- 不引入新导航框架、传感器高光、粒子、持续彩虹辉光。
- 不升级 Kotlin/Compose，不替换 Haze/Backdrop。
- 不新增 Macrobenchmark 前置依赖。
- 不把效果板文字直接当作最终 UI 文案。
