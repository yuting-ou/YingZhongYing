# 影中影 3.0「Liquid Controls」设计规格

## 目标

为 3.0.0-test1 建立一套可扩展的液态玻璃控件语言，首个落地场景是设置页性能调节：把现有 M3 平涂滑杆升级为带真实折射、按压形变、刻度与拖动值气泡的玻璃滑块，并把三个性能预设升级为液态分段选择器。

正式 3.0 将是视觉大版本；test1 先交付核心控件与性能页样板，不触碰转换核心、文件格式或数据语义。

## GitHub 参考与取舍

- [Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass)：`LiquidSlider` 使用独立轨道采样层、玻璃拇指、按压进度驱动 lens/chromaticAberration，并用速度做轻微 squash/stretch。吸收其光学层次，不复制其自定义手势实现。
- [OpenLiquidLauncher](https://github.com/LinuxKernel44/OpenLiquidLauncher)：`GlassSlider` 使用胶囊轨道、刻度、默认刻度与双击回默认。吸收刻度与默认档提示；双击重置与 M3 Slider 手势存在竞争，本版不做。
- 当前项目已有 Backdrop + Haze 玻璃体系，直接复用 `LocalGlassBackdrop`、`glassOptics()` 与 `continuousShape()`，不引入新依赖。

## 设计原则

1. **原生交互优先**：使用 Material3 `Slider` 的拖动、点击轨道、键盘/读屏与 `SetProgress` 语义；只替换 thumb/track 视觉。
2. **玻璃不是实色条**：轨道有内凹槽、渐变填充、移动镜面高光与刻度；拇指使用 Backdrop 折射、环境阴影、内阴影和顶部高光。
3. **动效有物理原因**：程序性改值用弹簧；拇指按压放大并增强透镜；拖动时显示值气泡；松手回弹；减少动效时全部直变。
4. **高频状态留在 draw/graphicsLayer**：按压、高光、速度形变不在组合层每帧重组整棵设置页。
5. **回退可用**：无 Backdrop/硬件折射时使用半透明玻璃膜与渐变，不影响可读性和点击。
6. **不破坏既有安全**：性能预设仍只改四个转换参数，不清玻璃画质、滚动降成本或减少动效设置。

## 组件与接口

### `GlassSlider`

```kotlin
@Composable
fun GlassSlider(
    value: Float,
    onValueChange: (Float) -> Unit,
    valueRange: ClosedFloatingPointRange<Float>,
    modifier: Modifier = Modifier,
    steps: Int = 0,
    enabled: Boolean = true,
    contentDescription: String,
    valueLabel: String,
    showTicks: Boolean = steps > 0,
)
```

- `value` 为外部真实值；组件内部维护显示值，拖动时直接跟手，程序性变化用 spring。
- M3 `Slider` 负责手势与语义；`Modifier.semantics` 补充 `contentDescription` 和 `stateDescription`。
- thumb 最小 28dp，Slider 触控高度保持 M3 默认 48dp。
- track 高 10dp；`steps > 0` 时绘制等距刻度；连续滑杆只画首尾微弱端点。
- 拖动/按住时显示玻璃值气泡，位置由纯几何函数计算；减少动效时直接显示/隐藏。

### `GlassPresetSelector`

```kotlin
@Composable
fun GlassPresetSelector(
    selected: PerfPreset?,
    onSelect: (PerfPreset) -> Unit,
    modifier: Modifier = Modifier,
)
```

- 三个等宽玻璃胶囊：省电 / 均衡 / 性能。
- 当前匹配预设显示选中态；自定义值不匹配任何预设时无选中项。
- 选中态用 spring 位移、透明度和镜面高光过渡；点击仍有 48dp 热区与 `Role.Button`/`contentDescription`。
- 预设点击继续触发现有 `CONFIRM` 触觉。

## 性能页信息架构

- 顶部保留自动/手动开关与说明。
- 手动挡顺序：液态预设选择器 → 四个玻璃滑块 → 安全兜底说明。
- 数值标签继续使用轻量上滑淡入；拖动时由滑块气泡承担即时反馈，避免双层提示重复。
- 自动挡保持现有文字摘要，不新增持续动画，避免省电设备无谓耗电。

## 视觉规格

- 轨道：`onSurface` 12% 内凹槽 + 1dp 内侧高光；填充使用 `primary → tertiary` 水平渐变。
- 拇指：28dp 胶囊/圆形玻璃，标准态 blur 10dp、lens 18dp；按压态 lens 28dp、blur 6dp、scale 1.12。
- 拖动速度：横向速度做 1.00～1.10 的轻微拉伸，纵向 1.00～0.94； clamp 在安全范围，减少动效时关闭。
- 值气泡：圆角 14dp 玻璃膜，文本 13sp，贴在拇指上方 10dp；不遮挡标题行。
- 预设胶囊：高 40dp、间距 8dp；选中态表面 alpha 提高、边缘高光增强，未选中态仍可读。

## 无障碍与减少动效

- 保留 M3 Slider 的 `ProgressBarRangeInfo`、范围与步进语义。
- `contentDescription = "转换并发，并发 5 张"`；读屏可感知当前值。
- 所有预设按钮 ≥48dp，`Role.Button`，文案与描述双通道。
- `LocalReduceMotion` 为真时：无 spring、无速度形变、无气泡位移动画；只保留静态玻璃和即时数值。

## 测试与验收

- 纯函数：归一化进度、刻度位置、气泡 x 坐标、速度形变 clamp。
- Compose 语义：`SetProgress` 能改变值；预设点击只改四参数；减少动效下无 infinite transition。
- 截图：性能页手动挡浅色/深色、2× 字号、减少动效；同时保存改造前后对比图。
- 模拟器：真实点击预设、拖动四个滑块、切换自动/手动；`dumpsys gfxinfo` 记录帧数/Jank/99 分位，`dumpsys meminfo` 记录 PSS。
- 无头模拟器只能验证回退膜、几何、交互和性能，不能证明真机 AGSL 折射观感；Release 说明必须如实标注。
