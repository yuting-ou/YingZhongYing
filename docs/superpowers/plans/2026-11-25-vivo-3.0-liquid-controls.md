# 3.0「Liquid Controls」实施计划

> **For agentic workers:** 本轮由主代理直接执行；每一步先写测试或验证探针，再实现。用户已授权无人值守推进到 3.0.0-test1 Pre-release，不发布正式 3.0。

**Goal:** 交付带液态玻璃滑块、液态预设选择器、拖动值气泡与物理动效的 3.0.0-test1。

**Architecture:** 新建独立 `GlassSlider.kt` 与 `GlassPresetSelector.kt`，复用 M3 Slider 手势/语义、现有 Backdrop/Haze 玻璃体系；性能页只替换视觉组件，不改参数语义。

**Tech Stack:** Kotlin、Jetpack Compose、Material3 Slider、Kyant0 Backdrop、Haze、Robolectric、Gradle。

**Spec:** `docs/superpowers/specs/2026-11-25-vivo-3.0-liquid-controls-design.md`

## Global Constraints

- 不新增依赖，不修改转换核心、XMP/字节格式或删除语义。
- M3 Slider 保留原生拖动、点击轨道、键盘/读屏与 `SetProgress`。
- 所有动效尊重 `LocalReduceMotion`；减少动效时无 spring、无限循环或速度形变。
- 玻璃必须有非折射回退，不能出现空白轨道或不可读拇指。
- 预设只修改并发/内存/扫描/缩略图四项，保留玻璃画质、滚动降成本与减少动效。
- 无头模拟器只能验证回退膜、几何、交互与性能，不能宣称真机 AGSL 观感已验收。
- `versionCode=135`、`versionName=3.0.0-test1`，只发 Pre-release。

## Review Focus

- `valueRange` 退化、越界值、steps=0/6：进度与刻度必须 clamp，不能 NaN。
- 拖动中程序性改值/松手：手指必须直跟，弹簧不能抢轴。
- `LocalReduceMotion=true`：不得创建 infinite transition 或持续动画帧。
- 无 Backdrop/硬件加速：轨道、拇指、气泡仍完整可读可点。
- 2× 字号/360dp：气泡与标题不重叠，预设三胶囊不挤出屏幕。
- 自定义参数不对应预设：选中态必须为空，不能假装命中“均衡”。
