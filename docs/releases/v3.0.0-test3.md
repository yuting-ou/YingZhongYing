# 影中影 v3.0.0-test3（测试版）

> 按 Kyant0/AndroidLiquidGlass 的按压手感补齐液态玻璃交互：按下鼓起、触点高光跟手、边缘色散。仍为测试版，正式 3.0 等你真机试玩后发布。

## 本版新增

- **按压鼓起**：性能预设胶囊、玻璃图标磁贴、次级按钮按下时轻微膨胀；滑块拇指按压缩放更明显，不再是缩小回弹。
- **高光跟手**：白色折射高光落在指尖位置；图标磁贴会把 48dp 触控代理坐标换算回视觉尺寸，高光不会偏到角落。
- **玻璃色散**：上缘青蓝、下缘玫橙，叠加红青通道偏移，随按压缩放同步增强；拖动滑块期间持续显示。
- **减少动效**：关闭弹簧与过冲，按下态直接切到静态鼓起与色散。

## 稳定性

- 小尺寸控件继续使用纯 Canvas 光谱膜，不挂 Backdrop/AGSL，避免复现 test1 的齿轮 RenderThread 闪退；大卡片与 Dock 仍保留真实 Backdrop 折射与 `chromaticAberration`。
- 实测模拟器 Release：设置齿轮、手动挡、预设切换与滑块拖动均无原生崩溃。

## 验证

- JVM 回归：478 条，5 条按条件跳过，0 失败。
- Robolectric 原生截图类改为每类独立 JVM，消除 `FileSystemAlreadyExistsException` 被 test-retry 掩盖的问题。
- lint、v3 签名 Release 构建通过；设备冒烟 19 条通过。

## 安装信息

- `versionCode = 137`
- `versionName = 3.0.0-test3`
- v3 签名，可从 2.8.0 正式版、2.9.0 候选包、3.0.0-test1 / test2 覆盖安装。
