# 影中影 v3.0.0-test10（液态玻璃展示型 + 动效优先）

> 在 test9 的苹果动效基础上，按用户批准的 B+C 路线强化材质、导航、控件与状态反馈；仍为测试版，正式 3.0 需真机视觉与性能确认。

## 本版打磨

- **玻璃材质展示型**：Thin / Regular / Thick 进一步拉开透明度、压暗、模糊和折射差异；Regular/Thick 加入受画质与兼容模式控制的上蓝下玫边缘色散，Thin 不进入 Backdrop。
- **主页 Hero**：Large Title 随列表/网格滚动收缩，顶部图标默认 Thin，底部 Dock 使用 Thick；照片氛围采样在兼容模式下停止加载。
- **Apple 分段控件**：列表/网格改为独立分段控件，具备 Role.Tab、选中语义、按压弹簧和 ≥48dp 热区。
- **导航连续性**：原图查看器支持下拉关闭；横向 pager 与下拉按累计主轴锁定，缩放/平移保持；相册面板按位移或速度关闭；页面转场增加轻微缩放与 Hero 弹簧。
- **设置信息层级**：卡片改为正文左缘对齐的紧凑分组列表，图标与开关靠右，减少嵌套卡片；全量布局测试恢复通过。
- **控件手感**：统一 Press 弹簧、取消回稳、无系统涟漪和单次确认触觉。
- **批量动效预算**：列表进度条与网格 spinner 共用忙碌数量预算；24 张同时忙碌只保留一个动态实例，滚动、兼容、减少动效时静态显示。
- **状态与无障碍**：空错态标题增加读屏标题与状态语义，主动作保证 48dp；骨架屏保持 Indeterminate，兼容模式不创建无限动画。

## 独立对抗审查

- 修复列表 busy 行仍创建无限进度条、批量预算落空的问题。
- 修复 Viewer 横翻起手后向下转弯会误触下拉关闭的手势主轴问题。
- 修复系统减少动效变化后 Large Title 仍使用旧缓存的问题。
- 未发现转换、MediaStore、删除/恢复语义改动。

## 验证

- JVM 全量回归：529 条，5 条按条件跳过，0 失败。
- `lintVitalRelease`、R8 与 v3 签名 `rotateSignRelease` 构建通过。
- 视觉矩阵覆盖浅/深、Thin/Regular/Thick、2× 字号、减少动效、兼容骨架、照片氛围和四态状态。
- host GPU 无头模拟器实跑：设置→关于→两次返回、相册切换、面板下拉、原图查看/下拉关闭/勾选/关闭、3 张网格转换、减少动效 + 2× 字号设置页均通过，无崩溃。
- Debug 模拟器网格转换采样：124 帧，janky 7 帧（5.65%），P90 32ms、P95 36ms、99th 46ms；进程 PSS 152,786KB、RSS 286,988KB。
- 上述数据来自 Debug 模拟器，不代表真机性能；真机 GPU 兼容性、玻璃观感和大相册表现仍需安装后实测。
- 正式 3.0 未发布。
