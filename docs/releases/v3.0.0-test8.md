# 影中影 v3.0.0-test8（网格动效细节打磨）

> 在 test7 基础上精简网格转换反馈：单转圈、忙碌文案即时更新、完成闪白更轻，降低多张并发的动画开销。

## 本版打磨

- **忙碌反馈精简**：网格卡片只保留一个旋转不确定弧与“转换中…”提示，移除重复的底部不确定进度条；每张忙碌卡片少一组无限动画。
- **状态不再滞后**：进入忙碌态时状态文案立即切为“转换中…”，不再短暂显示“待转换”；终态仍保留交叉过渡。
- **完成闪白收敛**：闪白透明度从 30% 降到 22%，时长从 450ms 收敛到 340ms，保留对勾徽标弹入。
- **失败反馈不变**：失败/丢位置徽标、抖动、语义色与拒绝触觉继续保留。
- **减少动效不变**：静态弧、无闪白/位移/结构动画。

## 验证

- JVM 回归：482 条，5 条按条件跳过，0 失败。
- host GPU 模拟器实跑 3 张网格转换：忙碌文案即时、单转圈、完成徽标与轻闪白均可见，无崩溃。
- lint、R8、v3 签名 Release 构建通过；设备冒烟 19 条通过。
- 正式 3.0 未发布。
