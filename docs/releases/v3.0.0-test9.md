# 影中影 v3.0.0-test9（苹果动效系统 · 液态玻璃打磨）

> 在 test8 的网格转换反馈基础上，完成一轮以空间连续性、材料层级、控件反馈和状态编排为主的动效收口。仍为测试版，正式 3.0 需真机视觉与性能确认。

## 本版新增

- **统一动效 token**：建立 Snappy / Standard / Gentle 弹簧与状态尺寸契约，系统减少动效开关变化即时刷新；缩略图、状态切换、原图缩放统一门控。
- **照片共享过渡**：网格照片到全屏原图查看器使用同一共享内容状态连续缩放，支持中途关闭；减少动效时直接切换。
- **导航连续性**：设置子页、修复覆盖层、破损修复与位置恢复按可见层级处理返回；相册面板支持下拉关闭；修复写入期间消费返回，查看器退场期间放行第二次返回。
- **控件反馈**：筛选 chip、相册行补齐选中语义、Role.Tab、≥48dp 触控和按压弹簧；弹窗按钮去掉系统涟漪，确认操作只触发一次 CONFIRM 触觉与动作。
- **状态编排**：选择器、修复时间、位置恢复和许可证加载接入统一加载/空态/错误/成功过渡；骨架屏只保留一个共享 shimmer 相位。
- **玻璃材质层级**：Thin / Regular / Thick 显式映射到透明度、压暗、模糊和折射；Thin 不进入 Backdrop 路径，小尺寸 Backdrop 安全门禁保留。
- **性能收口**：滚动或减少动效时，缩略图占位与骨架屏停止无限动画；玻璃画质档与滚动降成本逻辑继续叠加。

## 验证

- JVM 全量回归：506 条，5 条按条件跳过，0 失败。
- `lintVitalRelease`、R8 与 v3 签名 `rotateSignRelease` 构建通过。
- host GPU 无头模拟器实跑：设置 → 关于 → 两次返回、相册切换、面板下拉关闭、原图查看/勾选/关闭、3 张网格转换、减少动效 + 2× 字号设置页均通过，无崩溃。
- 模拟器网格转换采样：115 帧，janky 5 帧（4.35%），P90 24ms、P95 32ms；进程 PSS 67,228KB、RSS 200,924KB。
- 上述帧与内存数据仅代表本机模拟器，不代表真机性能；真机 GPU 兼容性、玻璃观感和大相册表现仍需安装后实测。
- 正式 3.0 未发布。
