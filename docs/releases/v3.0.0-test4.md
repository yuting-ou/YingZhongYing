# 影中影 v3.0.0-test4（液态玻璃 · Haze 2.1 测试版）

> 小尺寸控件接入 Haze 2.1 Glass：预设胶囊、滑块拇指与玻璃图标磁贴会采样真实背景做模糊/折射；按压鼓起、跟手高光与色散继续保留。
> 这是工具链大版本测试包，正式 3.0 仍需真机确认后再发布。

## 本版变化

- **Haze 2.1 Glass**：升级 Haze 到 2.1，新增 `haze-glass`；小控件不再只画玻璃膜，而是按自身位置采样背景，带模糊、边缘折射和色调。
- **按压手感**：按下轻微鼓起、白色高光跟随指尖、上青蓝下玫橙的色散边缘；减少动效时切静态。
- **保留稳定回退**：小控件不挂 Backdrop；无硬件加速/不支持 Glass 时仍有玻璃膜底与全部交互。大卡片与 Dock 继续使用 Backdrop 折射。
- **工具链**：Kotlin 2.4.21、Compose BOM 2026.09.00（Compose UI 1.12.1），适配 Haze 2.1。

## 已知边界

- Haze Glass 是真实背景采样，背景越有内容（照片/彩色纹理）越明显；纯色渐变页面上观感会比参考图克制。
- 真机 GPU 驱动兼容性需要你安装后实测；若有闪退/异常请直接反馈，我会退回 test3 的安全膜路径。
- 正式 3.0 尚未发布。

## 验证

- JVM 回归：478 条，5 条按条件跳过，0 失败。
- lint、v3 签名 Release 构建通过；模拟器 host GPU 验证 Glass 采样链路与按压无崩溃。
- Robolectric/无 GPU 环境走玻璃膜回退，截图矩阵保持可读。
