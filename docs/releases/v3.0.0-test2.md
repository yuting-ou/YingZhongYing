# 影中影 v3.0.0-test2（热修测试版）

> 修复 v3.0.0-test1 在真机点击设置齿轮时的 RenderThread 闪退。请不要再安装 test1。

## 修复

- **齿轮闪退**：定位为性能面板中小尺寸 Backdrop 折射节点在部分 GPU/驱动触发 `SIGSEGV`。液态滑块与预设胶囊统一改用多层玻璃膜，不再挂 Backdrop；现有大卡片/Dock 的折射保持不变。
- **稳定性**：移除小尺寸 `drawBackdrop` 后，模拟器 Release 的设置页、手动挡、预设切换与滑动均不再崩溃。
- **保留 test1 的交互**：玻璃轨道、渐变填充、刻度、镜面高光、拖动值气泡、按压/速度形变与液态预设胶囊全部保留。

## 验证情况

- JVM 回归：469 条，5 条按条件跳过，0 失败。
- 设备冒烟主机测试：19 条通过。
- 截图矩阵：浅色/深色、2× 字号、减少动效通过。
- 无头模拟器：设置齿轮、手动挡、预设切换、滑块拖动与回退膜通过；无 RenderThread 崩溃。
- 真机 AGSL 折射观感仍需用户后续过目；正式 3.0 尚未发布。

## 安装信息

- `versionCode = 136`
- `versionName = 3.0.0-test2`
- v3 签名，可从 2.8.0 正式版、2.9.0 候选包与 3.0.0-test1 覆盖安装。
