# 影中影 v3.0.0-test5（Haze Glass 细节打磨）

> 在 test4 的 Haze 2.1 Glass 上继续收口：选中态色温、玻璃边缘色散、渐变背景可读性、玻璃画质联动与按压细节。仍为测试版，正式 3.0 需真机确认。

## 本版打磨

- **选中态**：浅色主题选中胶囊改为更饱和的深蓝玻璃，文字保持高对比；深色主题保留薰衣草色玻璃。
- **边缘色散**：Haze Glass 增加轻量静态色散；按压时 Canvas 光谱膜继续叠加。关闭“玻璃画质”中的色散时，Haze 与按压光谱同步关闭。
- **渐变背景**：采样层加入不可见细点纹理，解决平滑渐变上折射不明显的问题；纹理不露到 UI，也不增加可见背景复杂度。
- **画质联动**：Haze 渲染模式跟随“标准/流畅”档；滚动暂停时自动降到 Performance，停手恢复。
- **按压细节**：预设、图标磁贴、主/次按钮、玻璃胶囊与滑块拇指统一鼓起、跟手高光与色散；减少动效保持静态。
- **回退可读性**：无 Haze/无硬件加速时仍保留玻璃膜底、对比度与全部语义。

## 验证

- JVM 回归：478 条，5 条按条件跳过，0 失败。
- host GPU 模拟器：浅色/深色、2× 字号、标准/流畅档、预设/滑块/齿轮按压检查通过，无原生崩溃。
- lint、R8、v3 签名 Release 构建通过。
- 真机 GPU 兼容性仍需你安装后实测；正式 3.0 未发布。
