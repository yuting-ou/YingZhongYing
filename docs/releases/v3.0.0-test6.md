# 影中影 v3.0.0-test6（液态玻璃 · 折射交互与安全模式）

> Haze Glass 接入真实按压折射/光照；新增玻璃兼容模式、原生崩溃自动恢复与照片氛围背景。仍为测试版，正式 3.0 需真机确认。

## 本版新增

- **真实按压折射**：预设胶囊、图标磁贴、滑块拇指把交互源接入 Haze Glass，按下时增强折射与光照；膨胀/回弹仍由统一弹簧控制，避免双重缩放。
- **玻璃兼容模式**：设置中可关闭 Backdrop/Haze 实时折射，只保留稳定玻璃膜与按压色散，适合 GPU 驱动异常机型。
- **原生崩溃自动恢复**：启动时读取 `ApplicationExitInfo`，若近期发生原生崩溃，自动开启兼容模式并提示；同一崩溃只自动处理一次，用户可在设置中关闭。
- **照片氛围背景**：可选开启，用当前首选照片的缩略图作为玻璃采样源；照片只在玻璃后显示，不上传、不改变页面底图，无照片时回退壁纸。
- **减少动效**：通用按压缩放也跟随减少动效即时切换；Haze 按压响应使用 Reduced 策略。

## 验证

- JVM 回归：481 条，5 条按条件跳过，0 失败。
- host GPU 模拟器：Haze 按压、照片氛围、兼容模式与原生崩溃自动恢复均通过，无崩溃。
- lint、R8、v3 签名 Release 构建通过；设备冒烟 19 条通过。
- 真机 GPU 兼容性仍需你安装后实测；正式 3.0 未发布。
