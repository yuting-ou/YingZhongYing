# 影中影 v3.0.0-test1（测试版）

> 3.0 首个视觉大版本测试包，核心主题是 **Liquid Controls（液态控件）**。2.8.0 正式版继续作为稳定版；3.0 正式版需真机过目后再发布。

## 本版亮点

- **液态玻璃滑块**：性能页四个自定义滑块升级为玻璃轨道、渐变填充、等距刻度、镜面高光与 Backdrop 折射拇指。
- **物理动效**：程序性改值弹簧、拖动直跟、按压透镜增强、速度拉伸、松手回弹；拖动时显示玻璃值气泡。
- **液态预设胶囊**：省电/均衡/性能改为三枚玻璃分段按钮，选中态实色主题底保证对比度，自定义参数不会误显示选中预设。
- **原生无障碍**：保留 Material3 Slider 的 `SetProgress`、范围与步进语义；禁用态增加回调保护；预设按钮 ≥48dp。
- **减少动效**：无 spring、无限循环或速度形变；保留静态玻璃与即时数值。
- **稳定回退**：无 Backdrop/硬件折射时使用完整玻璃膜；无头模拟器不再误入 Backdrop，避免 RenderThread 原生崩溃。

## GitHub 参考

- [Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass)：参考轨道采样、玻璃拇指、按压透镜与速度形变。
- [OpenLiquidLauncher](https://github.com/LinuxKernel44/OpenLiquidLauncher)：参考胶囊轨道、刻度与默认档提示。
- 本项目未复制其自定义手势，仍使用 M3 Slider 原生交互。

## 验证情况

- JVM 回归：469 条，5 条按条件跳过，0 失败。
- 设备冒烟主机测试：19 条通过。
- 截图矩阵：性能页浅色/深色、2× 字号、减少动效通过。
- 无头模拟器：预设切换、四个滑块拖动、模式切换、值气泡与回退膜通过；PSS 约 99MB。
- 无头软件 GPU 的帧统计不可作为产品性能结论：同页面普通滚动也有 96% Jank；需真机 GPU 复核。
- 真机 AGSL 折射观感尚未验证；正式 3.0 发布前必须由用户过目。
