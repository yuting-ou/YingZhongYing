# 影中影 v2.9.0-test1（测试版）

> 2.8.0 已发布正式版；本版是 2.9 系列首个测试版。v2.8.0-test10 为版本号误标，已被本版取代，请安装本版。

## 本版改进

- **大规模性能**：冷启动合并、清空撤销、单文件扫描去重、修复时间全选/半选判断完成 O(n²) 扫尾。
- **删除与落地恢复**：待删除 URI、待原名落地任务改为原子快照；覆盖进程死亡、删除结果跨重建、落地中途恢复与重复移动保护。
- **安全边界**：删除仍必须由用户确认；pending 落地禁用非幂等复制回退，失败时保留在中转目录并明确提示。
- **验证装置**：新增可重复的设备冒烟脚本，覆盖队列恢复、位置权限收回、三组 GPS 夹具转换和平台 EXIF 读回。
- **性能测量**：32MiB JPEG + 128MiB MP4 固定夹具累计分配 485MiB；缺真机 PSS/吞吐对照，T9 流式化继续暂缓。

## 验证情况

- JVM 回归：452 条，5 条按条件跳过，0 失败。
- 冒烟脚本主机测试：13 条通过。
- v3 签名 Release：无头模拟器完整冒烟通过，队列恢复、权限门禁、转换与 EXIF 读回均通过。
- GitHub Actions：单元测试与 Release 构建双绿后发布。

## 说明

- 本版为测试版，真实手机尚未验证。
- 不影响 2.8.0 正式版用户继续使用；安装前请确认版本名为 `2.9.0-test1`、versionCode 为 133。
