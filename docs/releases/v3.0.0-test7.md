# 影中影 v3.0.0-test7（网格转换动效）

> 补齐网格模式的转换反馈：忙碌暗幕、转圈、不确定进度条、状态交叉过渡、完成闪白/徽标弹入、失败抖动与结构动画。仍为测试版。

## 本版修复

- **网格转换中**：卡片图片上增加半透明暗幕、旋转不确定弧、底部不确定进度条与“转换中…”提示；并发处理时每张卡片独立反馈。
- **状态切换**：卡片语义色底色与状态文字颜色平滑过渡；状态文案交叉淡入淡出，不再硬跳。
- **完成/失败**：完成时短暂闪白并弹入对勾徽标；失败/丢位置弹入感叹徽标，失败同帧抖动并触发拒绝触觉。
- **结构动画**：网格项接入与列表一致的 `animateItem`，增删/重排有淡入、弹簧位移与淡出。
- **减少动效**：转圈改静态弧、抖动/闪白/结构动画关闭，状态与触觉反馈保留。

## 验证

- JVM 回归：482 条，5 条按条件跳过，0 失败。
- 新增网格 pending → busy → done 状态回归测试，覆盖忙碌/终态标签与减少动效分支。
- host GPU 模拟器实跑 3 张网格转换：忙碌暗幕/转圈/进度条、完成徽标与状态切换均可见，无崩溃。
